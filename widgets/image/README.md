# Image widget

Scriptable widget displaying the same usage information as the dark design over a
configurable image background. Background images are cached locally for 24 hours.

Copy `mobile-data-widget.js` into a Scriptable script named **Mobile Data Image**.
It uses the [shared usage helper](../shared/README.md) and currently needs the
central server. Follow the [widget setup guide](../README.md#set-up-in-scriptable).

Open [preview.html](preview.html) for a sample-data preview. The preview downloads
its background image. See the [customization guide](../README.md#image-background-design)
for image and overlay settings.
