# Dark widget

Compact Scriptable widget showing remaining data, usage progress, plan expiration,
and reading and execution timestamps on a dark background.

Copy `mobile-data-widget.js` into a Scriptable script named **Mobile Data Dark**.
It uses the [shared usage helper](../shared/README.md) and currently needs the
central server. Follow the [widget setup guide](../README.md#set-up-in-scriptable).

Open [preview.html](preview.html) in a browser for a sample-data preview without
usage API requests.
